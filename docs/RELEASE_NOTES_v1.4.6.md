# 时间剪史 v1.4.6

审计整改后的首个发布版。这一版没有新功能，做的是把"会丢数据""会静默失败""主线程卡顿""文档与代码相反"四类问题按实测逐条改掉，并把发布链路本身变成会失败的闸。

## 数据与可靠性

- **存档损坏不再连带删库**：解析失败时先把原件保全为 `history.corrupt-<时间>.json`（永不删除），再从滚动备份 `history.json.bak` 恢复；两条路都失败时仍保住被引用的图片文件。修复前实测：损坏存档 + 一次复制 ⇒ 图片 2 → 0。
- **菜单栏「清空未收藏」必须二次确认**：确认弹窗此前存在但没有调用者。
- **不再允许两份进程同时写同一份存档**：两份会各自轮询剪贴板、各自整库写回，后写的整片盖掉先写的。现在启动时若发现同 bundle 的另一实例，本次启动静默退出。
- **降级不再毁数据**：读到比本版本更高的存档时改为只读打开并说明原因，不会把新格式写回旧格式。
- **成批清理过期记录会给出提示**（含条数与"请检查系统时间"），常规单条过期不打扰。刻意不做"猜时钟异常就不裁剪"的启发式 —— 无法与"两个月没打开"区分，宁可把数字显示出来由人判断。

## 隐私

- 设置 → 隐私 新增「数据与保留」：保存位置、保存内容类型、500 条 / 30 天、收藏长期保留、清空语义、敏感内容提醒。这些说明此前只写在代码里，产品从未显示。
- 菜单栏标题脱敏：疑似密钥 / 令牌 / 密码不再显示原文。
- 推荐反馈不再保存剪贴板原文，并随删除 / 清空级联清理；导出失败不再假装成功。
- 日志默认关闭，只在 `CLIPBOARD_HISTORY_DEBUG=1` 时写 `~/Library/Logs/时间剪史/`（目录 0700、文件 0600、拒绝符号链接目标）；OCR 日志只记长度不记内容。
- 自动粘贴所需的 `NSAppleEventsUsageDescription` 进入 bundle，文案明确"仅发送 ⌘V，不读取其他应用的内容"。

## 正确性

- 浏览器链接不再被当成本地文件条目（否则"再次复制"必失败）。
- 重复复制保留来源 App 归因，推荐因子不再被自己清空。
- 推荐排序确定化：同一份历史在两次启动之间不会再给出不同结果；同一条记录不再占两个推荐名额。
- 敏感内容前缀规则收紧，普通词不再被误判。
- 自动粘贴失败现在会说明原因并指向「系统设置 → 隐私与安全性 → 自动化」；未授权时记录仍已复制到剪贴板，可手动粘贴。

## 界面

- 设置侧栏未选中行的图标恢复可见（此前浅色主题下几乎看不见）。
- 破坏性的「清空」按钮不再在两个设置分类里各放一份。
- 5 处承载信息的文字对比度提升：暗色 2.22:1 → 5.79:1，亮色 1.89:1 → 3.98:1。
- 展开 / 收起与缩放尊重系统「减弱动态效果」。
- 纯图标按钮补齐无障碍名称（此前只有悬停提示，VoiceOver 读不到），并加静态守卫防止回归。

## 发布链路

- `Info.plist` 改为模板生成 + 逐键校验，缺任一必需键即构建失败（此前是 20 行 `PlistBuddy` 且每行 `|| true`，缺键也能"构建成功"）。
- `make dmg` 同时产出 `.sha256` 并自校验。
- 发布脚本新增闸门：`make dmg` 没有真的重写 DMG 就拒绝发布，防止把上一版字节当成本版归档并配上"自洽"的校验值。
- 新增 CI workflow（构建零告警 + 执行用例数只准涨不准跌 + 发布脚本测试 + plist 闸）。

## 本版未覆盖（不当作已验证）

- macOS 12 / 13 / 14 的**运行时**行为：编译期由 `.macOS(.v12)` 目标与可用性守卫保证（未加守卫的新 API 会编译失败），但未在三套系统上实跑。
- VoiceOver 实际朗读内容；hover、拖拽选择、快捷键录制态的界面表现。
- Gatekeeper 与 Apple 公证：本版仍是本地 ad-hoc 签名，首次打开需要手动允许（Developer ID 见 #14）。

## 兼容与回滚

- 最低系统 macOS 12 Monterey；Intel + Apple Silicon 通用二进制。
- **数据格式不变**：`history.json` 仍是 v1，字段只加可选不删改，旧版本可读回本版产物。新增的 `.bak` 与 `history.corrupt-*.json` 是附加文件，旧版本忽略即可 ⇒ **降级可运行**，回滚不产生需要清理的残留。
- 首次使用自动粘贴会请求一次「自动化」授权；拒绝不影响记录保存。
