# AI 剪贴板长期愿景

## 1. 产品北极星

「时间剪史」当前是一个传统 Clipboard Manager：记录历史、搜索、预览、再次复制。长期方向不是做另一个 Paste、Maccy 或 Raycast Clipboard History，而是把剪贴板从“被动历史列表”推进到“主动粘贴系统”。

目标体验：

```text
现在：复制 → 复制 → 打开历史 → 找内容 → 粘贴
未来：复制 → 复制 → 工作 → ⌘V → 系统推测最可能需要的内容
```

核心变化是：用户不再需要记住复制顺序，也不再需要经常打开历史列表。AI 不是搜索框旁边的附加按钮，而是理解剪贴板、当前上下文和用户习惯的核心能力。

## 2. 设计原则

1. **本地优先**：剪贴板天然包含高敏感内容。默认能力应尽量在本机完成，联网 AI 必须由用户明确开启。
2. **可解释预测**：预测粘贴不能像黑箱。系统应能说明“为什么推荐这一条”。
3. **不抢用户控制权**：AI 可以推荐、排序、预填，但不应静默替用户粘贴错误内容。
4. **渐进增强**：传统列表、搜索、快捷键必须继续可靠存在。AI 失败时退回普通剪贴板管理器。
5. **低延迟优先**：粘贴动作必须接近即时。AI 推理不能阻塞 `⌘V` 的基础路径。
6. **隐私分层**：上下文采集、云端发送、长期记忆分别授权，不能捆绑开启。
7. **Provider 中立**：不能把架构锁死在单一模型厂商。

## 3. 未来体验层级

### L0：传统历史

当前能力：文本、图片、文件、多文件记录，搜索，预览，收藏，菜单栏，快捷键。

### L1：智能整理

- 自动生成条目摘要
- 自动分类：代码 / 链接 / 文件 / 图片 / 地址 / 邮箱 / 命令 / 密码疑似项
- 语义搜索：搜“刚才那个 GitHub 链接”而不是精确关键词
- 相似内容合并或分组

### L2：上下文感知推荐

- 根据当前前台 App、窗口标题、最近复制内容，重新排序候选项
- 在菜单栏或快捷键面板中显示“最可能粘贴”的 3 条
- 用户仍手动确认

### L3：Predictive Paste

- 用户按 `⌘V` 或专用快捷键时，系统给出最可能内容
- 可配置为：先弹出确认 / 按住修饰键直接粘贴 / 对高置信度场景自动粘贴
- 始终提供撤销、历史回退和“为什么推荐”

### L4：工作流级剪贴板代理

- 识别用户正在进行的任务：写邮件、填表、提交代码、整理资料
- 主动保留相关资料，淡化无关内容
- 与 App Intents / Shortcuts / Spotlight / 文件上下文联动

## 4. 不做什么

- 不把剪贴板内容默认上传到云端。
- 不让 AI 改写用户要粘贴的原始内容，除非用户明确选择“改写/总结/翻译”。
- 不为了 AI 删除传统历史列表。
- 不做无法解释且难以关闭的自动粘贴。

## 5. 成功指标

短期：

- 搜索次数下降，但成功再次复制次数不下降。
- 用户更多使用快捷键/菜单栏候选，而不是打开完整窗口。
- 用户能够理解推荐原因。

中期：

- AI 推荐首位命中率稳定提升。
- 用户手动滚动历史列表的频率下降。
- 隐私设置被理解并被主动使用。

长期：

- 对常见工作流，用户形成“复制资料后直接工作，粘贴时系统知道我要哪条”的信任。
