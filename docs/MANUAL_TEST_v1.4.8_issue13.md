# 手工核对清单 · issue #13 右键菜单汉化

为什么需要这份清单：仓库里的自动化判据能钉住"我们交给 AppKit 的那份菜单是什么内容"，
但**钉不住"屏幕上真弹出来的样子"** —— `NSMenu.popUpContextMenu` 是模态的，实测在
`NSMenu.didBeginTrackingNotification` 里连 `cancelTrackingWithoutAnimation()` 都叫它不返回
（详见 `AGENT_DECISIONS.md` D-032）。所以下面这几条要用人眼看一遍。

版本：`main` 上的 issue #13 修复（v1.4.8 之后）。构建：`cd ClipboardHistory && swift build`，
运行：`open .build/arm64-apple-macosx/debug/时间剪史.app`（或 `make bundle` 后的产物）。

## 1. 搜索框 · 编辑态（这条是 issue #13 的主案发现场）

| # | 操作 | 期望 |
|---|---|---|
| 1.1 | 点一下左侧搜索框，让光标在里面闪，然后在框内**右键** | 弹出 **撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选** 六项，全中文，没有第二块分隔线以下的东西 |
| 1.2 | 同一次菜单里逐项目右标题 | **没有** 快速查看附件、字体、书写方向、布局方向、拼写和语法、替换、转换、语音、服务、查询、共享、表情与符号、自动填充 |
| 1.3 | 按 `Esc` 关掉，**不要**点任何一项 | 菜单关闭，搜索框仍在编辑态，光标位置没变 |
| 1.4 | 输入几个字（中文输入法组字中途也试一次），再右键选「全选」→「复制」 | 全选生效；输入法组字过程中候选框不被打断 |
| 1.5 | 右键选「撤销」（或 `⌘Z`） | 撤销走响应链上的 undo manager；若本框没有可撤销操作，该项显示为**灰色**而不是消失 |

## 2. 搜索框 · 非编辑态

| # | 操作 | 期望 |
|---|---|---|
| 2.1 | 先点窗口别处让焦点离开搜索框，然后**在搜索框上右键**（此时框里已经没有光标） | 同样弹出 1.1 那六项，全中文 |

## 3. 详情只读区

| # | 操作 | 期望 |
|---|---|---|
| 3.1 | 选中一条记录，在右侧详情文本区右键 | 弹出 **复制 / 全选 / 查找…** 三项，没有第四项 |
| 3.2 | 先选中一部分文字再右键，点「复制」 | 复制的是**选中的那段**，不是整条 |
| 3.3 | 点「查找…」 | 打开系统的查找浮层，能搜、能高亮 |
| 3.4 | 同一次菜单里找一遍 | 没有 1.2 列出的任何系统项 |

## 4. 别的控件的右键必须**不受影响**（拦截器的认领范围）

| # | 操作 | 期望 |
|---|---|---|
| 4.1 | 在左侧列表的某一行上右键 | **不弹任何菜单**（本产品没有行级右键菜单）；不能弹出一份"撤销/剪切/…"的编辑菜单 |
| 4.2 | 在筛选 pill（全部 / 收藏）、工具栏按钮上右键 | 同样不弹编辑菜单 |
| 4.3 | 在设置窗口里任意位置右键 | 不弹编辑菜单 |

## 5. 窗口级系统项（`allowsAutomaticWindowTabbing` 关掉之后的回归）

| # | 操作 | 期望 |
|---|---|---|
| 5.1 | 主窗口标题栏右键 / 「窗口」菜单 | 没有「显示全部标签页 / 隐藏标签栏 / 将标签页移到新窗口 / 合并所有窗口」 |
| 5.2 | 拖拽标签区域 | 主窗口不能被系统自动分成标签页（单窗口工具，本来就不该有） |

## 6. 一键复跑自动化那部分

```sh
cd ClipboardHistory
swift test --filter ChineseTextContextMenuTests                    # 13 例，普通环境就跑
CLIPBOARD_HISTORY_UI_INTERACTION=1 swift test --filter \
  'UIInteractionProbeTests/testRightClickMenusAppKitWouldShowAreChinese'
```

第二条会自己开一扇在屏窗口并抢前台；它**只**量"交给 AppKit 的那份菜单"，所以它绿不等于上面
1.1 / 3.1 的观感已经核对过 —— 那两条仍然要人眼。若它挂住超过 20 秒并打出
`WATCHDOG 探针挂住：拦截断了…`，说明拦截器断了（此时你手上正有一份模态系统菜单），
按 `Esc` 关掉即可，不要当成机器故障。
