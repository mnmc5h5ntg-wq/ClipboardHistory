# 时间剪史 v1.4.8

这一版的主线是**少跑腿、少等待、少意外**：常用的动作搬到了眼前，几处会静默丢数据或卡住的地方补上了边界，
另外修掉了一个"新包一打开就闪退"的问题（只影响本轮开发构建，线上 v1.4.7 不受影响）。

## 新增

- **双击列表里的条目 = 直接复制这一条**。以前要选中它、再把鼠标移到窗口右下角的浮层上点"再次复制"。
  按住 shift 或 command 时双击不会复制——那两个键是范围选择/多选，误双击不该动你的剪贴板。
- **行首的星标可以点**，一键收藏/取消收藏。这颗星以前在未收藏时是完全透明的，等于看不见这个入口；
  现在两种状态都看得见（对比度按可交互控件 ≥3:1 校准过），点它只改收藏、不会改变你当前的选择。
- **拖拽双向打通**：条目可以拖出去（文本拖成文字、图片拖成 PNG、单个文件拖成文件引用）；
  也可以把文件拖进左侧列表入库（一次拖多个会记成一条"多文件"记录，与在 Finder 里复制多个文件的形状一致）。
- 只含网页链接的剪贴板内容现在也会被记录（以前会被静默丢掉，你根本不知道它没进来）。

## 改进

- 左侧列表支持**方向键移动选择**，真实 Tab 键可以走到搜索框；清除按钮有提示文字。
- 菜单栏下拉面板会区分**"正在整理推荐…"**和**"暂无推荐"**——以前推荐还在算的时候会说"暂无推荐"，那是把"还不知道"说成"没有"。
- 亮色主题下控件描边终于可见（以前有几处几乎和背景同色，看不出按钮边界）。
- 破坏性确认框（清空历史）里 **Return 现在是"取消"**，"清空"不再是默认按钮，也不再带快捷键。
- 系统"减少动态效果"开启时，筛选标签的动画和悬停放大都会收敛。
- 详情预览加了 8 秒兜底：以前遇到取不出信息的视频会无限转圈。
- 隐私说明里补上了"记录复制时的来源 App 名称"这一项及其用途（只用于本机推荐排序）。
- 推荐理由不再在同一行里把来源 App 说两遍（以前会出现 `文本 · Safari · … · 回到Safari` 这种句子）。

## 修复

- **启动闪退**：本轮开发构建里，App 一打开就退出。原因是给 AppDelegate 加测试接缝时漏了 ObjC 的 `-init`；
  已修，并在发布流程里加了一道"反汇编产物、确认没有这个桩"的闸门——以前发布链路没有任何一步真的打开过这个 App。
- 双击之后左侧列表外围出现一整圈蓝色焦点环：已抑制（macOS 14 及以上；12/13 系统没有对应开关，仍会出现）。
- 存档里若存在两条相同 id 的记录，打开推荐时会崩溃：已改为保留第一条并正常显示。
- 快捷键录制完成后，按钮会一直显示"请输入快捷键"，直到界面刷新才恢复：现在立刻回显新组合。
- 保存不再重写没有变化的图片文件：以前每存一次都会把库里所有图片重编码一遍，图片越多越慢。
- 超长文本的显示统计改成有界计数，超大截图按 4096px 上限降采样（4K 及以下逐字节不变，不会被悄悄改画质）。
- 只读标志、来源 App 归属等若干"重启后丢失"的小问题一并修掉。

## 数据与兼容

- 最低系统 macOS 12 Monterey，Intel + Apple Silicon 通用二进制。
- **存档格式未变（仍是 v1）**，只新增了两个可选字段（来源 App 的 bundle id 与名称）：
  v1.4.8 直接读旧存档，缺字段按空处理；如果回退到 v1.4.7，这两个字段会被忽略，不会报错。
- 本版为本地 ad-hoc 签名、未经 Apple 公证：首次打开请 Control-点击 →「打开」，或在系统设置里允许。

## 还没做到的

- 推荐排序仍在本机规则内，没有接任何模型；AI 相关脚手架已从产品二进制中移出。
- 未做 Apple 开发者签名与公证。
- 多文件条目的"拖出"暂未支持（需要更底层的拖拽会话，怕做半截反而更糟，所以留着）。
- 键盘能否用 Tab 走到列表行，取决于系统设置里的「完全键盘访问」是否开启，这一条没有在你机器上复测过。
