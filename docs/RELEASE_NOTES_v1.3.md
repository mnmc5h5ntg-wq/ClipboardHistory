# 时间剪史 v1.3

v1.3 是“持久化版本”：时间剪史从临时剪贴板工具升级为可以长期依赖的剪贴板历史管理器。

## 本次更新

- 历史记录现在会保存到本机，重启应用后文本、图片、文件引用和缩略图仍可恢复。
- 新增收藏夹，重要内容可以固定保留，并可在侧边栏和菜单栏收藏区快速使用。
- 新增开机启动设置，支持在系统允许时让时间剪史登录后自动打开。
- 新增菜单栏快速复制最近记录/收藏记录。
- 新增“再次复制当前选中记录”快捷键，默认 `⌃⌥C`，并可像呼出主窗口快捷键一样在设置里修改。
- 清空历史现在只清空未收藏记录，收藏内容会保留。
- 历史去重升级为全局去重，同一张图片隔多条记录后再次复制也会合并为一条。
- 视频预览默认静音播放，关闭主窗口会停止播放；竖屏和宽视频的播放控件布局也做了修复。
- 保持 v1.2.1 及以前的固定边栏视觉，移除边栏折叠按钮和折叠功能。
- 新增并完善发布脚本、发布流程文档和自动化测试。
