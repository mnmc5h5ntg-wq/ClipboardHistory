## 3. 审查维度与合并结论

### Security Agent

主要结论：

- 当前没有发现传统意义上的网络攻击面高风险。
- 真正重要的是剪贴板工具天然存在隐私风险。
- 明文持久化、菜单栏摘要、完整文件路径展示，都可能暴露密码、验证码、token、截图、聊天缓存路径或项目路径。

建议方向：

- 首次启动明确说明本机持久化剪贴板历史。
- 增加暂停记录 / 隐私模式。
- 菜单栏支持隐藏内容摘要。
- 文件路径默认脱敏，只在详情或用户主动操作时显示完整路径。

### Quality Agent

主要结论：

- 部分失败路径会被当成成功路径处理。
- 快捷键注册、剪贴板写入、文件预览、文档同步这几块需要更明确的错误反馈。
- 有些文档描述已经落后于当前实现。

建议方向：

- 所有系统边界操作都返回明确结果：成功、失败、失败但已回滚。
- 自动测试覆盖负路径。
- 发布前同步 README、CHANGELOG、架构文档、许可证说明。

### Bug Hunter Agent

主要结论：

- 剪贴板再次复制失败时，历史可能仍被置顶。
- 快捷键注册失败回滚不可靠。
- 文件被移动或删除后，预览和再次复制仍可能继续走旧路径。
- 图片去重曾依赖 `NSImage` 对象身份，无法稳定识别相同内容。
- 主窗口识别依赖不稳定窗口 identifier。

建议方向：

- 优先修复“看起来成功但实际失败”的问题。
- 文件不存在时给出明确 UI 状态。
- 以内容 hash 做图片去重。
- 为主窗口设置稳定 identifier。

### Concurrency & Performance Agent

主要结论：

- 当前功能能跑，但大图、大视频、外接盘文件、iCloud 文件会放大主线程压力。
- 视频缩略图生成、图片缩放、全量持久化写盘，是下一阶段最值得处理的性能点。
- `Task.detached` 与 `@unchecked Sendable` 掩盖了 AppKit 对象跨线程风险。

建议方向：

- 剪贴板入口只做轻量解析。
- 缩略图和预览加载移到后台，并支持取消和超时。
- 持久化做 debounce 或后台串行写入。
- 后台任务尽量返回 `Data`、URL、String 等安全数据，再在主线程创建 `NSImage`。

### Architecture Agent

主要结论：

- v1.3 的主方向正确：已经从临时剪贴板工具，开始变成长期历史管理器。
- 核心模块方向成立：`HistoryStore`、`MediaLoader`、`ClipboardWriter`、`ApplicationShell`。
- 仍有几个边界需要继续收口：菜单栏快速复制、视频预览文件、剪贴板入口媒体处理。

建议方向：

- macOS 13+ `MenuBarExtra` 也统一走 `ApplicationShell`。
- `DetailPreviewViews.swift` 后续拆出视频控制器、播放状态和时间格式化。
- `ClipboardIntake` 不再直接承担缩略图生成和重媒体处理。

## 5. 推荐修复路线

### 阶段 1：可靠性热修

目标：修掉“看起来成功但实际失败”的问题。

1. 剪贴板写回失败处理。
2. 快捷键注册失败回滚。
3. 主窗口稳定 identifier。
4. 图片内容 hash 去重。
5. 文件不存在时预览失败、再次复制失败。

验证：

```bash
swift test --package-path ClipboardHistory
```

人工测试：

- 文本复制与再次复制。
- 图片连续复制去重。
- 文件复制后删除源文件，再打开预览和再次复制。
- 修改快捷键为冲突组合，再恢复。
- 菜单栏与快捷键显示主窗口。

### 阶段 2：稳定性与性能

目标：大图、大视频、大历史量下不明显卡顿。

1. 视频缩略图生成移到后台。
2. 图片缩放和预览加载避免阻塞主线程。
3. 持久化改为后台 debounce。
4. 视频播放器切换和关闭时释放旧资源。

验证：

- 复制大图片。
- 复制大视频。
- 快速切换多个视频条目。
- 收藏、删除、清空大量历史。

### 阶段 3：隐私产品化

目标：让用户知道保存了什么，并能控制暴露范围。

1. 首次启动或设置页说明本机持久化。
2. 增加暂停记录 / 隐私模式。
3. 菜单栏隐藏内容摘要。
4. 清空全部，包括收藏。
5. 文件路径默认脱敏显示。

验证：

- 隐私模式下不记录新内容。
- 菜单栏隐藏文本摘要。
- 清空未收藏仍保留收藏。
- 清空全部确实删除收藏与图片文件。

### 阶段 4：架构与发布收口

目标：减少维护分叉，准备更正式的 beta。

1. 统一菜单栏快速复制到 `ApplicationShell`。
2. 拆分 `DetailPreviewViews.swift`。
3. 继续收窄 `ClipboardIntake` 职责。
4. 发布脚本支持事务式回滚。
5. 同步 README、CHANGELOG、架构文档、许可证和安装说明。
