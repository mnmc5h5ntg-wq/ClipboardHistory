## 你要做的事
逐个元素回答：**这里加动效有没有积极作用**。积极作用只有三类：
① 让状态变化可读（"什么变了"）；② 暗示功能或层级（"这是什么/在哪一层/能不能点"）；③ 提供回执（"我收到了你的操作"）。
三类都占不上的，就**明确写"不加"和理由**（高频、常驻动画、与系统语义冲突、抢注意力、纯装饰）。
不要提出"看起来更炫"但说不出作用的东西。

## 已经**实测证伪**的事，不要再提（提了就是浪费一轮）
1. **`List`（NSTableView 后端）的行级 `.transition` 四种写法全部跑不出来**：一帧跳变。
   侧栏行的过渡已因此被砍（账本 D-055 / M1），并且有一条源码守卫禁止再把 `.transition` 挂到 `List` 行上。
2. **`Animation.linear(duration: 0)` 会让带 `.transition` 的插入永不落地**（必须 0.001）。
3. **系统 symbol effect（`contentTransition(.symbolEffect(.replace))` / `symbolEffect(.bounce)`）在离屏抓帧下两臂读数相同** —— 量不到，
   所以"加了符号动效"只能记成"源码已接、产物未量"，不许宣称已交付。
4. **`CADisplayLink` 在显示器休眠时 0 tick、`Timer` 会被 App Nap 节流** ⇒ 任何常驻循环都要走已有的自旋抓帧时钟。
5. **详情区整块淡入 = 一帧空白**（M4 的原始写法），现在挂在"视图类型身份"（`DetailPreviewKind`）上才成立。
6. **合成鼠标事件在 xctest 进程里驱动不了 SwiftUI Button 的按下跟踪**（`keyWindow=nil`）；
   **`cacheDisplay` 抓的是模型树**，抓不到 AppKit 图层动画与部分系统合成层。
7. **热键呼出路径不动画**（QuickPick / 主窗口呼出刻意 `.none`，规范与四家同类核对过）。
8. 常驻动画是负债：菜单栏常驻进程里不许留任何无限循环动画（骨架扫光是唯一例外，且只在加载期存在）。
