## 4. 轴是怎么来的（源码侧，已核实在）

- `QuickPickController.swift` 里 `stack` 四条边约束 `constant: 12`、`edgeInsets` 全 0
  ⇒ 字段与表格的**框**都从 12pt 起；文字 12.5 = 12 + `NSTextField` 自身内缩。
- 胶囊 22.0 = 12 + **另一层 10pt**（对称）⇒ 那 10pt 属于 `NSScrollView`/`NSTableView` 那一层的**行内缩**，
  不是对齐问题。**这 10pt 具体由哪个 API 给的仍未实测** —— 要实测就得改一次常数再重拍，
  而那正是 R103 要做的事（改之前它是假设，不是结论）。
- 148② 有答案：浮层那颗是 AppKit `QuickPickSearchField`（`QuickPickController.swift:202`，
  `isBordered=false drawsBackground=false`），主窗口侧栏那颗是 SwiftUI `SearchField`
  （`HistorySidebarView.swift:12`，自带 `.padding(.horizontal, 9)`）⇒ **两个容器，不需要两处一起改**。
