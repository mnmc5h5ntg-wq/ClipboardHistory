## D-575（2026-11-04 · R575 = 第 574 轮 / Round 572）：分类法要写成会红的函数；交集要从两个独立数推出来；"删掉一行声明"是最便宜的假绿

① **一句"硬判据"必须被逐条问"拿哪条通道判、那条通道今天到不到数"，而答案要写成会红的函数，不是文档里的表。**
    D12 那句列了八条（角度单调 / 投影宽度按余弦律 / 模糊半径递增 / 亮度单调下降 / 边框锐度不变 / 透明区 alpha 归零 / 框架只在透明之后缩一次 / 屏上帧间隔不超标），从写下到今天**没有被逐条问过**。本轮的落地是 `UICaptureTests.testTheD12HardClausesEachNameAChannelThatEitherReadsOrIsNamed`：
    八条**声明**（写死在表里）× 三条**现扫探针**（角度驱动文件数、折叠路径文件数、折叠期改 alpha 文件数）+ 两条**现量通道**（夹具必经点 `render` 的产物、产品浮层树补 651 丙臂前置之后的离屏 alpha 栅格）+ 一条**环境键读数**（真机录屏那档今天开没开）⇒ `d12WitnessState(channelReads:objectExists:needsRealScreen:)` 派生出**实测态**，逐条断言 `实测 == 声明`。
    为什么这样切：声明与实测分在两栏，任何一边漂了都会红；如果两边读同一个来源，那把尺就恒真（R540/R565 那一族"自我豁免的恒真门"）。

② **交集必须从两个独立数推出来，不许靠"同一个文件里两个词都出现过"。**
    本轮第一次写 `countFoldAlphaWriters` 用的就是共现：`文件里出现 Collapse 字样 && 出现 isOpaque` ⇒ 命中 **1 个文件**，而那一个是 `AppDelegate.swift`（它建折叠控制器 + 按 D4a 写了 `window.isOpaque = false`），**跟"折叠期间改 alpha"没有关系**。后果不是"读数难看"，是**两条声明当场被这条假实测推翻**（`透明区alpha归零`、`框架只在透明之后缩一次` 被算成 `runner可判`）。
    修法是把它拆成两格独立现读：`折叠路径文件数=2`（`foldProgress` / `setCollapsed(` / `isTransitioning`）与 `折叠期改alpha文件数=0`（前者 ∩ alpha 写入），并加一条 `foldPathFiles >= 1` 的证人 —— 没有它，"交集为 0"既可能是"确实没有对象"也可能是"扫描扫不到任何东西"（尺瞎了）。刀 M1512 钉的就是丢掉合取那一支。

③ **扫描类探针读不到目录时必须返回 -1，不许返回 0。**
    `countProductFiles` 在 `enumerator` 建不出来时给 **-1**，而调用处断言 `>= 0` ⇒ "扫不到"与"扫到 0 个"是两种结局，后者才是"今天无证人"的依据。这是 R565 那一族（量不到不许伪装成判过）在**源码扫描**这一侧的形状，与像素侧同一条规矩。

④ **"删掉一行声明"必须红，因为它是这张表最便宜的失效方式。**
    `XCTAssertEqual(rows.count, 8)` + 刀 M1509（真删一条）钉住：少一行不会让那条硬判据消失，只会让下一轮以为它不存在。同一形状在账本里已经出现过两次（R566 的新增具名 skip 漏登记、R574 的写手抄两遍）——**名单类判据的失效永远是"少一项还绿"**，所以条数本身就是判据。

⑤ **这张表不许把第③段的验收悄悄改成"只有手感"。**
    现读是 `runner可判=0 只能真机=1 今天无证人=7`。如果就此写"那八条由用户签字即可"，D12 那句"两边都过才算完成"实际上被删掉了一边，而它的退回条件（"任一边不过就退回一步切换"）就没有可执行的判据。⇒ 本轮的处理是把取舍摆成 BACKLOG 654：要么先决定哪几条能在着色器之前就做成 runner 可判（角度单调与投影宽度两条可以只靠 `foldProgress` + 窗口宽度序列判），要么明确接受"这八条今天只有手感那一半"。**这个选择归用户，本轮不代选，也没动第③段一个字。**

⑥ **文档自己内部两处归属不一致时，登记"谁改的 + 凭什么这么读"，旁注不许改闸门。**
    647 那一腿：§3 第 2 条（闸门）列在第②段，`D4a 落地补注`（旁注）推到第③段。R574 按 §3 收回但只在台账里说；本轮按派单 ③ 补上文档里的登记（改动人 = R575 的 ZiyiWang 会话/执行代理，依据 = 用户派单，理由 = 旁注不许改闸门），R574 那两条更正原文一条不删。⇒ 规矩：**"按哪一条读"这件事必须落在文档里，落在台账里只活一轮。**
