⑤ **push 换通道只走用户已经装好的那份凭据，并且成因读不到就具名归用户。**
    SSH 那支今天被服务器拒（`Permission denied (publickey)`、`ssh-add -l` 无身份、`ssh -v` 确实递了那把无口令的 key），
    而 `gh` 装好的 HTTPS token 那条能推 ⇒ 用 `git push https://…` 同一支仓同一支分支，

    那把 key 为什么今天不被接受 = `SSH_KEY_REJECTED_REASON_UNKNOWN`，**留给用户处置**；
    第一趟 HTTPS 得 `remote rejected … (Internal Server Error)` 是 GitHub 侧瞬时 500，隔 20s 原样重试即过（具名而不是绕路）。
